# Victory Check — мобильное приложение

Прототип мобильного клиента по техническому заданию **Victory Check** (фиксация нарушений охраны труда на строительных объектах).

Реализовано как **PWA** (Progressive Web App): открывается в браузере телефона, можно установить на главный экран как обычное приложение. Не требует App Store / Google Play и сборки через npm.

## Возможности (раздел 5.1 ТЗ)

| Экран | Функции |
|--------|---------|
| Авторизация | Email/телефон, пароль, «Забыли пароль?» |
| Список нарушений | Поиск, быстрые фильтры, карточки со статусами и сроками, FAB «+» |
| Создание (7 шагов) | Объект → организация → категория → фото (камера) → описание → серьёзность → подтверждение |
| Детали | Галерея, информация, история, комментарии, смена статуса, отчёт об устранении |
| Аналитика | KPI: всего, % устранено, просрочено, критические |
| Профиль | Данные пользователя, настройка уведомлений, выход |

Дополнительно: нумерация `КОД/ГОД/НОМЕР`, расчёт сроков по серьёзности, GPS при создании, локальное хранение данных.

## Как открыть на телефоне

### Вариант 1 — локально на ПК, затем с телефона в одной Wi‑Fi сети

1. В папке `victory-check-mobile` запустите простой сервер (нужен для камеры и PWA):

   **PowerShell:**
   ```powershell
   cd "c:\Users\operator\Desktop\Новая папка\victory-check-mobile"
   npx --yes serve -l 3000
   ```
   Если `npx` недоступен, откройте `index.html` напрямую в Chrome на ПК для проверки (камера на телефоне лучше через HTTPS/localhost).

2. Узнайте IP компьютера: `ipconfig` → IPv4 (например `192.168.1.10`).

3. На телефоне в Chrome/Safari откройте: `http://192.168.1.10:3000`

4. **Установить приложение:** меню браузера → «Добавить на главный экран» / «Установить приложение».

### Вариант 2 — только на компьютере

Дважды щёлкните `index.html` или перетащите файл в Chrome. Для входа используйте любой email и пароль (демо-режим).

## Демо-данные

- Объекты: ЖК «Северный», ТРЦ «Галерея», складской комплекс  
- Подрядчики: ООО «Строймонтаж», ИП Петров, АО «СпецСтрой»  
- 3 примера нарушений с разными статусами  

## Дальнейшая разработка (по полному ТЗ)

**Вне scope (пока):** Telegram / MAX бот — отложено.

**В приоритете:**
- Backend API (PostgreSQL, JWT, загрузка медиа в S3)
- Мобильный клиент (нативный React Native / Flutter или доработка PWA)
- Push через FCM/APNs
- Веб-панель администратора
- Офлайн-очередь синхронизации, ЭЦП предписаний
